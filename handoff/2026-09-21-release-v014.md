## 本版内容（相对 v0.1.3）

1. **日志中心**：「错误日志」→「启动器日志」（递归 `files/log/` 全目录）；新增「AzurPilot日志」页（按天 txt + error 现场截图）；统一尾部加载查看器（512KB 尾块 + 加载更早，治整读 OOM 隐患）。
2. **导出双分**：`azurpilot_logs_*.zip`（官方 issue 格式、近 7 天、镜像 `log/` 相对路径）与 `launcher_logs_*.zip`（维持原收集、常驻附 properties.txt）；旧 `azurpilot_logs_` 前缀 zip 顺带清理。
3. **自动清理**（默认开）：冷启动静默删 >7 天 AzurPilot txt/error 目录（`LogCleaner`，Timber.w 留痕）；`session.log` 在 `ProotHost.cleanupStale()` 截尾留 2MB；关闭开关弹确认框警告。
4. **调试模式整链删除**：开关/字段/重启链/休眠 logcat 链全删；app.log 定格常驻全量落盘；死代码死串清理（AnsiAnnotatedText、run_log_* 等）。

## 发版过程坑点（网络）

- 直连 github.com 超时（curl 000）；探测本机常用代理端口，**127.0.0.1:7897 可用**（Clash 系）。
- git：`git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=... push`（命令级，未改配置）；gh：`HTTPS_PROXY` 环境变量。
- `gh release create` 连资产一把梭在 PATCH 阶段 EOF（代理断连，服务端未残留 release）→ 改**两段式**：先建空 release，再 `gh release upload` 传资产，一次成功。
