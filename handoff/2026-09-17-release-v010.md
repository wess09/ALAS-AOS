# Handoff 2026-09-17 · v0.1.0 首个公开发布

> 上一篇：`2026-09-17-tools-touch.md`（工具独立开启 + 触摸转发，用户终验通过收官）。本篇记 v0.1.0 发版全案与发布后的项目状态。

## 决策（用户指令）

- **候选 1「崩溃自动恢复」放弃**：用户质疑「怎么分辨是我退出的？后台自拉起=隐形性能消耗」——成立。现语义（点开 App 才恢复环境）即为正确产品语义，不再动。
- **阶段五 -1 多 ROM / -2 长稳 / -5 shizuku-m 产品化**：用户另有安排，跳过。阶段五只做 -6 Release。

## 发版事实

- **产物**：`更早的旧名-v0.1.0-android-arm64.apk`（307MB，rootfs 内置），GitHub Release `v0.1.0` @ [Shinarin/AzurPilot](https://github.com/Shinarin/AzurPilot/releases)。tag `v0.1.0` = commit `26eea36`。
- **版本派生**（既有机制）：tag → versionName `0.1.0`；versionCode=45（commit 数）。
- **ABI**：release 仅 arm64-v8a（rootfs ARM64 + proot 不模拟，x86_64 无意义）。
- **签名**：`keystore/azurpilot-release.jks`（RSA4096/30 年，gitignored）+ `app/local.properties` KEYSTORE_* 四键（gitignored）。**两坑已录 devlog**：PKCS12 不支持 store/key 异密码（重建同密码）；semi-icons `verifyReleaseResources` 独立链接不认 classpath 符号（本地 attrs.xml 同 format 声明解决，上游同坑）。
- **真机冒烟（全新安装=一键安装 DoD）全过**：Shizuku 授权 → 解压 315MB → 热更新 → wrapper/gui 在岗 → 挂机页全 UI → 开始挂机（游戏拉起+登录链）→ 停止挂机（环境保留）。证据截图 `.tmp/rel-0{1..4}-*.png`。

## 下次发版流程（复用）

1. 业务提交完毕 → `git tag -a vX.Y.Z` 钉在最终提交（versionName 才准）。
2. `cd app && JAVA_HOME=... GRADLE_USER_HOME=... gradlew.bat assembleRelease`（签名自动从 local.properties 取）。
3. 验证：`apksigner verify --print-certs` + `aapt dump badging`（versionName/label/native-code）。
4. 真机冒烟（覆盖安装即可，同签名）。
5. `gh release create vX.Y.Z <apk> --notes-file ...`；devlog 分段 + handoff 同步。
